# 1/9/2026 12 PM - Heavily Modified Schematic

_Time spent: 2.0h_

So firstly, I realised that to use the master and slave approach, I needed a TRRS which connects the halves via UART. This meant that I needed a UART_TX, UART_RX but all my gpio pins were occupied. After some research I found that the nice!nano v2 was a good choice as it had the same Nordic chip. This allowed for bluetooth connection, a built in linear Li-Po charging circuit which helps avoid clutter. Furthermore, I added a 2 pin JST-PH connector for the Li-Po battery. There is also an RGB LED which will signal green for charged, yellow for 50$, red for low and blue for charging.
